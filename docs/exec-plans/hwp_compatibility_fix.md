# Problem 1-Pager: HWP Form Compatibility Fix

## Background
사용자가 기존 "한글 2018"에서 꼼꼼하게 서식을 맞춘 원내 양식(진단서, 외래 안내문 등)을 새로운 대체 프로그램인 `ndbHwp`에서 열었을 때 레이아웃이 겹치거나 문단이 깨지는 문제가 보고되었습니다. Gemini의 분석에 따르면, 이는 렌더링 엔진(`rhwp`)이 복잡한 서식 데이터(160% 줄간격, 절대 위치 표/글상자 배치)를 완벽하게 해독하지 못해 발생합니다.

## Problem
`ndbHwp`의 코어 렌더링을 담당하는 `third_party/rhwp`는 업스트림 벤더 저장소(Submodule)로 읽기 전용 상태입니다. 따라서 렌더링 엔진 코어 자체의 로직을 직접 패치하여 호환성을 달성하는 것은 불가능합니다. 

## Goal
`third_party/rhwp` 모듈을 직접 수정하지 않고도, 문제가 되는 HWP 파일들이 `ndbHwp` 환경에서 올바르게 표시되도록 호환성 보정 수단을 제공해야 합니다. 

## Non-goals
- 완벽하게 HWP 2018과 동일한 렌더링 엔진 자체를 새로 개발하거나 교체하는 것.
- 모든 HWP 문서를 대상으로 한 파서 변경. (특정 깨짐 속성 변환에 집중)
- `third_party/rhwp` 저장소 내 코드 수정 (업스트림 PR 제외).

## Constraints
- 수정 작업은 `apps/desktop` 또는 `apps/studio-host`에 한정되어야 합니다.
- 수정으로 인해 정상적인 문서가 손상되어서는 안 됩니다.
- 변환 로직 적용 후 문서를 저장할 때 원본의 서식 호환성 정보가 대체 프로그램 규격으로 덮어씌워질 수 있음을 고려해야 합니다.

## Implementation Outline
`apps/desktop`의 네이티브 Rust 레이어(`src-tauri/src/state.rs` 혹은 전용 모듈)에서 문서 코어를 로드할 때(또는 사용자가 명시적으로 변환을 요청할 때), `DocumentCore` 객체를 순회(traverse)하며 호환성 문제를 유발하는 속성들을 재지정합니다:
1. `lineSpacing`이 0이거나 비정상적인 음수일 경우 160%와 동등한 정상값으로 변경.
2. 서로 겹치는 다수의 절대 좌표형 표/글상자를 감지하여 "글자처럼 취급(Inline)" 속성으로 일괄 변환하여 레이아웃 무너짐 방지.

## Verification Plan
1. 사용자 제공 샘플 파일(`sample/외래대장안내문.hwp`, `sample/건강진단서 (실습학생용)0.hwp`)에 변환 적용.
2. `pnpm tauri dev`를 통해 실행한 UI에서 해당 표 레이아웃과 줄 간격 겹침이 해소되었는지 직접 검증.
3. 변환 후 PDF 내보내기/저장 기능이 정상 동작하는지 확인.
